# VaseForge

Parametric, trend-driven vase generator. It produces watertight models that
are guaranteed printable on FDM printers, and it has an AI assistant that
turns text or images into design *parameters*. The AI never produces meshes.

Status: **design review** (Phase 0).

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): architecture overview
- [src/core/params/schema.ts](src/core/params/schema.ts): complete zod parameter schema
- [docs/GEOMETRY.md](docs/GEOMETRY.md): geometry, effect and printability formulas
